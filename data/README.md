# data/

Put the source PDF here. It is not included in this repository (the PDF states "All rights reserved to Microsoft").

Download `employee_handbook.pdf` from the `data/` folder of Microsoft's sample project:
https://github.com/Azure-Samples/azure-search-openai-demo

Then run the pipeline from the main folder (see the main README, Quick start):

```bash
python src/extract.py data/employee_handbook.pdf
```
